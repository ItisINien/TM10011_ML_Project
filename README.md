**Project Title** 

Machine Learning Analysis for Differentiation of Benign and Malignant Liver Tumors

Authors
Lieve Bron (5051266)
Nienke Hendriksen (5542618)
Loïs Staleman (5324335)
Jos Vork (5763908)
Description

This repository contains code for training and evaluating machine learning models (Random Forest, SVM, Logistic Regression) to differentiate benign and malignant solid liver tumors using radiomic features extracted from T2-weighted MRI scans.

Dataset
Dataset: Worcliver (186 patients, 493 features)
Note: Dataset not included due to privacy; contact the authors for access.
Features were preprocessed: constant features removed, Spearman correlation filtering applied, normalized using RobustScaler.
